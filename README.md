# SILENCE: DEMON REALM

A dark survival game where you must survive the Demon Realm for 90 seconds.

## 🎮 How to Play

- Use the **Arrow Keys** to move.
- Every movement increases **Chaos**.
- If Chaos reaches 100%, you lose.
- Red demons will chase you.
- Enter glowing cyan **Safe Zones** for temporary protection.
- Survive for **90 seconds** to win.

## ⚔️ Features

- Demon enemies with chasing behavior
- Chaos system
- Temporary safe zones
- 90-second survival challenge
- Real-time score tracking
- Dark atmospheric visual design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
